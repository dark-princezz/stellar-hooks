# create-stellar-hooks-app

Scaffold a production-ready Stellar dApp in seconds, powered by [stellar-hooks](https://github.com/dark-princezz/stellar-hooks).

## Quick Start

```bash
# Using npm
npm create stellar-hooks-app@latest my-app

# Using npx
npx create-stellar-hooks-app my-app

# Using yarn
yarn create stellar-hooks-app my-app

# Using pnpm
pnpm create stellar-hooks-app my-app
```

## Options

- `-t, --template <name>`: Template to use (default: `vite-react`)
- `-f, --force`: Overwrite target directory if non-empty
- `-h, --help`: Display help
- `-v, --version`: Display version number

## Available Templates

- `vite-react`: Vite + React 18 + TypeScript + Freighter wallet connection + testnet balance viewer

## Next Steps

```bash
cd my-app
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
