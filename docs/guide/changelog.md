# Changelog

Recent changes and updates to stellar-hooks.

## Version 0.2.0

### New Features
- Added comprehensive JSDoc documentation to all hooks
- Improved error handling with typed transaction errors
- Enhanced network mismatch detection
- Added auto-connect support for multiple wallets
- Improved caching strategies

### Bug Fixes
- Fixed Freighter API v2 migration issues
- Resolved timeout handling in wallet connections
- Fixed polling deduplication logic
- Corrected type definitions for branded types

### Breaking Changes
- Updated to @stellar/stellar-sdk v13
- Changed network configuration API
- Updated Freighter API integration

## Version 0.1.0

### Initial Release
- Core wallet integration (Freighter, Albedo, xBull, Rabet)
- Account and balance hooks
- Transaction building hooks
- Soroban contract support
- Network management
- Basic caching and polling
