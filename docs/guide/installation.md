# Installation

Get started with `stellar-hooks` in your React project.

## Prerequisites

- Node.js 16+ 
- React 18+
- A Stellar wallet (Freighter recommended for development)

## Install via npm

```bash
npm install stellar-hooks
```

## Install via yarn

```bash
yarn add stellar-hooks
```

## Install via pnpm

```bash
pnpm add stellar-hooks
```

## Peer Dependencies

`stellar-hooks` requires these peer dependencies:

```json
{
  "react": "^18.0.0",
  "@stellar/stellar-sdk": "^13.0.0"
}
```

Make sure you have these installed in your project:

```bash
npm install react @stellar/stellar-sdk
```

## TypeScript Support

`stellar-hooks` is written in TypeScript and includes full type definitions. No additional setup is needed for TypeScript projects.
