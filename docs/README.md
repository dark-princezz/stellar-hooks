# stellar-hooks Documentation

This directory contains the VitePress documentation site for stellar-hooks.

## Development

```bash
npm run docs:dev
```

The documentation site will be available at `http://localhost:5173`

## Build

```bash
npm run docs:build
```

The built documentation will be in `docs/.vitepress/dist`

## Preview Production Build

```bash
npm run docs:preview
```

## Structure

- `docs/.vitepress/` - VitePress configuration
- `docs/guide/` - Developer guides
- `docs/hooks/` - Hook reference documentation
- `docs/api/` - API reference
- `docs/examples/` - Example applications
