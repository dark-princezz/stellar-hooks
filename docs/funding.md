# Funding and sustainability

stellar-hooks is an open source project under the MIT license. This page says how it is paid for and how to help.

## How the project is funded today

- **Maintainer time** is volunteered. There is no company behind the project and no paid staff.
- **Infrastructure** (CI, the nightly testnet and futurenet runs, documentation hosting) runs on free tiers
  of the services the repository already uses.
- **Bounties** on selected `good first issue` items are paid through Algora; see [BOUNTIES.md](../BOUNTIES.md).
- Direct sponsorship is available through the repository's **Sponsor** button
  ([`.github/FUNDING.yml`](../.github/FUNDING.yml)).

If any of this changes, this page is updated in the same pull request.

## What funding would be used for

In priority order:

1. **Maintenance**: reviewing pull requests, triaging issues, and keeping up with `@stellar/stellar-sdk`,
   Freighter and Soroban protocol releases, which break integrations often.
2. **Reliability**: the testnet and futurenet integration runs, end-to-end tests, and any paid CI minutes
   they need.
3. **Bounties**: small payments that let new contributors take well-scoped issues.
4. **Documentation and examples**: guides, migration guides and sample apps.
5. **Security**: dependency and release hygiene, and an external review of the signing code paths if
   funding allows.

## How to contribute financially

- **Sponsor** the maintainers with the repository's Sponsor button.
- **Fund a bounty** on an issue you care about; ask in the issue.
- **Organizations**: if your product depends on stellar-hooks, sponsoring is the most direct way to keep the
  dependency healthy. Open an issue or contact the maintainers to discuss recognition and priorities.

## How to contribute without money

Code, documentation, bug reports with a reproduction, and answering questions in issues are all valuable. See
[CONTRIBUTING.md](../CONTRIBUTING.md).

## Transparency

The [roadmap](../ROADMAP.md) is public. When funding reporting is set up (for example on Open Collective),
it will be linked here.
