# stellar-hooks Vite + React Starter

A starter template for building decentralized applications on Stellar and Soroban using [stellar-hooks](https://github.com/dark-princezz/stellar-hooks), Vite, React, and TypeScript.

## Features

- ⚡️ **Vite + React 18 + TypeScript** for blazing fast development and type safety
- 🌐 **StellarProvider** pre-configured for Stellar Testnet
- 👛 **Wallet Connection** with `@stellar/freighter-api` and `useFreighter` hook
- 💰 **Live Account Balances** with `useStellarBalance` (Native XLM and custom trustline tokens)
- 🎨 **Minimal & Modern UI** styled with clean CSS

## Getting Started

### Prerequisites

1. Install Node.js (v18 or higher)
2. Install the [Freighter Wallet](https://www.freighter.app/) extension in your browser and switch to **Testnet**

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

```bash
npm run build
```

### Linting

```bash
npm run lint
```
