## How to Run Locally

```bash
cd examples/sandboxes
npm install
npm run dev
```

## Try Online Sandbox

For a complete working example with multiple hooks, check out the [Try Online](../try-online/) sandbox:

```bash
cd examples/try-online
npm install
npm run dev
```

## Features

The Try Online sandbox includes:
- ✅ Wallet connection examples
- ✅ Account and balance viewers
- ✅ Simple payment sender
- ✅ Path payment (asset swap) with slippage
- ✅ All examples use Testnet
