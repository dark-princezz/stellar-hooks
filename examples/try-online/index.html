🌊 Stellar Hooks

Try Stellar development online - no installation required

Quick Start

Stellar Hooks is a React library for building Stellar applications. This sandbox provides a minimal template to get started with common hooks like wallet connection, payments, and account management.

import { useFreighter } from "stellar-hooks";

const { connect, isConnected, publicKey } = useFreighter();

return (
  { !isConnected && <button onClick=connect>Connect</button> }
  { isConnected && `Connected: ${publicKey}` }
);

Note: To test wallet connections, install the Freighter browser extension or use Albedo for web-based testing.

Pro tip: Fork this sandbox and experiment with hooks like usePayment, usePathPayment, useStellarAccount, and more.

Available Hooks

Try these hooks in your sandbox:

  • ✨ useFreighter - Connect Freighter wallet
  • ✨ useAlbedo - Connect Albedo web wallet
  • ✨ useWallet - Unified wallet adapter
  • ✨ usePayment - Send XLM or assets
  • ✨ usePathPayment - Multi-hop asset swaps
  • ✨ useStellarAccount - Fetch account details
  • ✨ useStellarBalance - Get balances
  • ✨ useTransaction - Build and submit transactions
